## 作品について

楚辞と近思録の原文。楚辞は王逸の章句と朱熹の集註によった標註と解題を付け、楚世家節略などの附録を添える。近思録は解題のあと十四巻を収める。冨山房が『漢文大系』の一冊として出した、原文に訓点・頭注・標注を付けた版。大正 5 年（1916 年）刊。巻頭の標題・目次・奥付・広告は入れていない。

## 本文の作り方

国立国会図書館デジタルコレクション（インターネット公開）の全文テキスト（OCR）をそのまま収めた。1 段落が底本の 1 コマ（見開き）。校正はしていないので、振り仮名や柱の混じり、読み違いが残る。
